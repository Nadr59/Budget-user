# BaitBudget — ميزانية البيت

تطبيق أندرويد لإدارة ميزانية البيت ومديونية البقالات.

## المميزات
- تسجيل مشتريات البقالة وتسجيل المدفوعات
- حساب المديونية تلقائياً لكل بقالة
- ملخص أسبوعي وشهري وشامل
- تقارير مفصلة
- مطابقة الحسابات في نهاية الشهر
- واجهة عربية سهلة الاستخدام

## التقنيات
- Kotlin
- Jetpack Compose
- Room Database
- MVVM Architecture
